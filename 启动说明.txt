============================================================
 TalentMatch AI  —  JD / 简历智能匹配 Agent
 使用说明
============================================================


【一、怎么启动】

  解压后，双击  TalentMatchAI.exe

  程序会自动打开浏览器。
  如果没有自动打开，手动访问：  http://127.0.0.1:7860

  注意：
    * 那个黑色命令行窗口是程序本体，别关它。
      关掉窗口 = 关闭程序。
    * 想要停止，直接关闭命令行窗口即可。


【二、不需要下载模型，开箱即用】

  向量模型已经打包在压缩包里（models 文件夹），
  不需要联网下载，也不需要额外配置。

  首次启动会花 10~20 秒加载模型，之后就快了。


【三、必须先配置 API Key】

  程序需要一个 DeepSeek API Key 才能工作：

    1. 打开界面左侧的「系统设置」
    2. 在「DeepSeek API Key」里填入你的 Key（sk- 开头）
    3. 点「保存配置」
    4. 建议顺手点一下「测试连接」，看到“连接成功”就对了

  API Key 只保存在你自己电脑上，
  不会上传到任何服务器。


【四、怎么用】

  1. 「JD 管理」   → 上传岗位 JD
                     （支持 PDF / DOCX，也可以直接粘贴文本）

  2. 「简历库」     → 上传候选人简历
                     （同样支持 PDF / DOCX / 粘贴文本）

  3. 「AI Agent」   → 先从上方选择岗位和简历，
                     再用中文提问，例如：

                       · 帮我筛选最适合这个岗位的 5 个候选人
                       · 这份简历适合哪些岗位？
                       · 对比这几个候选人的优势和不足
                       · 分析这个岗位最看重哪些技能

  4. 「数据管理」 / 「系统设置」 → 查看知识库、改 API 配置


【五、常见问题】

  Q：双击后一闪就没了？
  A：多半是缺少 VC++ 运行库。装一下这个就好了：
     https://aka.ms/vs/17/release/vc_redist.x64.exe
     （Win10 / Win11 一般自带，不用管）

  Q：提示连接失败 / 找不到 API Key？
  A：到「系统设置」检查三样东西：
       · API Key  是否正确（sk- 开头）
       · Base URL 是否为 https://api.deepseek.com
       · 点「测试连接」看具体报错

  Q：上传 PDF 提示「提取不到文字」？
  A：这份 PDF 是扫描件（整页都是图片，没有文字层）。
     解决办法：改用「方式二 · 直接输入」，
     把 JD / 简历内容直接粘贴进去。

  Q：7860 端口被占用？
  A：程序会自动改用 7861、7862……
     以命令行窗口里打印的地址为准。

  Q：models 文件夹能删吗？
  A：不能。里面是向量模型，删了就没法用了。


【六、数据存在哪】

  所有数据都在 exe 同级目录，随时可备份或删除：

    data\uploads\    上传的原始文件
    data\chroma\     向量数据库
    data\config.json API 配置（含 Key，注意别外传）
    models\          向量模型（程序自带，别动）
